## 一，交换机配置

### 1.连接交换机

连接console接口（COMx），设置波特率。

Linux：
```sh
screen /dev/ttyUSB0 9600
```

Windows，额外设置数据位 8、无校验(n)、停止位 1、无流控(N)：
```ps1
$port = New-Object System.IO.Ports.SerialPort COM3,9600,None,8,one
$port.Open()
```

### 2.视图

默认进入的是用户视图，功能是执行查看类命令，进行网络诊断和状态监控，用户视图下不能修改配置。

```
<Hostname> display interface brief
<Hostname> ping
<Hostname> tracert
<Hostname> display mac-address
<Hostname> save
```

在用户视图下运行`system-view`会进入系统视图，进行全局配置，可配置设备名称、管理IP、创建VLAN、启用全局功能，并由此进入各类子视图。

```
[Hostname] sysname SW-Core
[Hostname] clock timezone BJ add 08:00:00
[Hostname] vlan batch 10 20 30
```

在系统视图下运行`interface ethernet x/y/z`进入以太网视图，用于配置该特定接口的物理属性、链路层特性及IP地址。

```
[Hostname-Ethernetx/y/z] port link-type access / port link-type trunk / port link-type hybrid
[Hostname-Ethernetx/y/z] undo portswitch # 三层交换机模式
```

在系统视图下运行`vlan x`进入VLAN视图，用于创建和管理vlan。

```
[Hostname-vlanx] port GigabitEthernet 0/0/1 to 0/0/10
```

在系统视图下运行`acl 2000`进入acl基本配置视图（仅匹配源IP），运行`acl 3000`进入acl高级配置视图（可匹配协议、源/目的IP、端口等），用于ACL的规则集。

```
[Hostname-acl-basic-2000] rule 5 permit source 192.168.10.0 0.0.0.255
[Hostname-acl-adv-3000] rule 5 deny tcp destination-port eq 80
```

### 3.配置管理功能

系统自带的，常用的三种管理功能：
- telnet协议（windows）
- ssh协议（linux）
- web管理服务（厂商）

telnet协议需要在三种视图中配置，在系统视图下开启服务；在用户接口视图配置认证方式和协议；如需用户名密码认证，还需进入aaa视图创建本地用户并授予Telnet服务权限。

```
[Hostname] telnet server enable 
[Hostname] telnet server-source -i Vlanif 10
[Hostname-ui-vty0-4] protocol inbound telnet
[Hostname-ui-vty0-4] authentication-mode aaa
[Hostname-aaa] local-user admin password irreversible-cipher YourPassword@123
[Hostname-aaa] local-user admin privilege level 15
[Hostname-aaa] local-user admin service-type telnet
```

SSH 需要在三种视图中配置，与 Telnet 的差异在于多了一个前置步骤——生成 RSA 密钥对（SSH 加密通信的基础）。在系统视图下生成密钥对、开启 STelnet 服务并指定源接口；在用户接口视图配置认证方式和接入协议为 SSH；最后进入 AAA 视图创建本地用户，并将其服务类型显式设置为 ssh，否则 SSH 登录会被拒绝。

```
[Hostname] rsa local-key-pair create
[Hostname] stelnet server enable
[Hostname] stelnet server-source -i Vlanif 10
[Hostname-ui-vty0-4] protocol inbound ssh
[Hostname-ui-vty0-4] authentication-mode aaa
[Hostname-aaa] local-user admin password irreversible-cipher YourPassword@123
[Hostname-aaa] local-user admin privilege level 15
[Hostname-aaa] local-user admin service-type ssh
```

Web 管理需要在两种视图中配置：在系统视图下开启 Web 服务（HTTPS 随之启用）；在 AAA 视图创建本地用户，并将其服务类型显式设置为 http（涵盖 HTTPS），否则无法登录 Web 界面。

```
[Hostname] web-manager enable
[Hostname] aaa
[Hostname-aaa] local-user webadmin password irreversible-cipher YourWebPassword@123
[Hostname-aaa] local-user webadmin privilege level 15
[Hostname-aaa] local-user webadmin service-type http
```

## 二，服务器配置

### 1.配置界面

不同按键，进入配置界面：
- BIOS（Setup）
- 启动项（Boot Manager/PXE）
- RAID（LSI）

BIOS常用的配置：
- VT虚拟化支持
- NUMA，性能优化
- HDC配置，AHCI/RAID
- 带外管理，IPMI BMC
  - 网口模式，shared/dedicated/adaptive
  - Restore on AC Power Loss <power off> 
  - BMC的IP配置，Source/Addr/Mask/Gateway

带外管理的接口：
IPMI/BMC/ILO/HDM/IMM/mgmt

带外管理常用功能：
- 远程控制，显示服务器当前画面
- 固件升级
- 电源控制
- 虚拟介质，本地iso通过网络挂载，安装操作系统
- 辅助排查故障

RAID配置：
- 硬盘加入到raid中

### 2.操作系统

安装方式：
- U盘/DVD
- PXE

制作系统盘：
- ultraiso

手动分区：
- Linux
  - swap
  - /
- Windows
  - 恢复分区
  - 系统盘

PXE安装：
- 搭建母机
- 多台服务器快速安装操作系统。

### 3.基础运行配置

网络配置，冗余网卡做组合
ntp，同步计算机时钟
防火墙配置
远程telnet，ssh端口号
域管理
